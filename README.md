# 🚀 Node.js Local JSON Database API

A structural backend repository built with Node.js and Express.js that reads and streams relational data records directly from a localized JSON database system file (`database.json`).

## 🛠️ Architecture Stack
- **Runtime Environment:** Node.js
- **Routing Engine:** Express.js 
- **Storage Layer:** Local JSON File System Architecture (`fs` module integration)

## 📡 Core API Endpoint Channels
- **`GET /`** -> Baseline server running health check verification.
- **`GET /api/users`** -> Streams full array list profiles from the JSON cluster records.
